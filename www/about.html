About this project

This is a Computer Networks lab assignment built around socket programming in C++, covering both Windows and Linux using a shared net.hpp wrapper.

What it demonstrates

  • Basic TCP client-server communication (daytime, echo)
  • A simple HTTP server serving files from disk
  • Message framing - handling TCP's stream of bytes as complete lines, even when split or merged
  • Handling multiple clients: one thread per client, and the more efficient select() approach
  • A multi-user chat system with nicknames, a user list, and broadcast messaging

Requirements met

  • All example programs run with screenshots
  • Chat system meets every requirement in Section 11.2
  • No #ifdef outside net.hpp - chat_server.cpp and chat_client.cpp are fully portable
